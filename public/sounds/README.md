# Notification Sound Setup

This directory should contain your notification sound file.

## Quick Setup

1. Download a notification sound file (MP3 format)
2. Save it as `notification.mp3` in this directory
3. The file will be served automatically at `/sounds/notification.mp3`

## Recommended Sound Specifications

- **Format:** MP3
- **Duration:** 0.5 - 2 seconds
- **File Size:** < 100 KB
- **Bitrate:** 128 kbps or higher

## Where to Get Sounds

- Freesound.org - Free sound effects
- Zapsplat.com - High-quality free sounds
- YouTube to MP3 converters - Convert from videos
- Online generators - Create your own sounds

## Testing

Once you've added `notification.mp3`:

1. Visit the Notifications page in your business dashboard
2. Grant notification and audio permissions
3. Send a test notification
4. You should hear the sound on your device

## Troubleshooting

If sound doesn't play:
- Check that `notification.mp3` is in this directory
- Verify browser has notification and audio permissions
- Check browser console for errors (F12)
- Try a different MP3 file to test compatibility
